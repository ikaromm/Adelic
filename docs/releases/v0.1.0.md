# Adelic v0.1.0

Primeira versão do aplicativo local para conversar com agentes e delegar tarefas de projetos. Inclui interface web e desktop Linux x86_64, com tema escuro, histórico persistente e roteamento adaptativo para manter perguntas simples no caminho curto.

## Downloads

- `Adelic-0.1.0-linux-x86_64.AppImage`: aplicativo desktop com Node e SQLite incorporados.
- `Adelic-0.1.0-linux-x86_64.AppImage.sha256`: checksum SHA-256 do pacote.
- `install-linux.sh`: instalador opcional do comando e atalho no menu do usuário.

Baixe os assets pela [release v0.1.0](https://github.com/ikaromm/Adelic/releases/tag/v0.1.0). Para abrir:

```bash
sha256sum -c Adelic-0.1.0-linux-x86_64.AppImage.sha256
chmod +x Adelic-0.1.0-linux-x86_64.AppImage
./Adelic-0.1.0-linux-x86_64.AppImage
```

Se a montagem AppImage estiver indisponível, acrescente `--appimage-extract-and-run`. Para instalar o atalho, baixe também o instalador e execute `bash install-linux.sh ./Adelic-0.1.0-linux-x86_64.AppImage`.

## Recursos

- Conversas com streaming, cancelamento, aprovações quando disponíveis e histórico SQLite.
- Chats avulsos, + por projeto e seletor para vincular/desvincular mantendo mensagens.
- Modos Auto/Rápido/Completo. Perguntas simples usam um executor, sem carregar ferramentas, memória ou grafo automaticamente.
- Orquestrador por projeto, delegação com dependências, revisão e resumos compactos; saídas completas são carregadas sob demanda.
- Graphify por projeto para orientar buscas em código e ai-memory com escopo explícito.
- Codex e Kiro com execução real validada pelas CLIs oficiais, descoberta de modelos e autenticação existente.
- Janela Electron isolada, backend automático em porta livre de loopback, mesma base do modo web e encerramento dos agentes ao fechar.
- Descoberta de agentes fora do mise, com PATH de lançamento gráfico e overrides validados.

## Validação e limites

Typecheck, build e **88 testes em 11 arquivos** passaram. O AppImage foi executado fora do repositório com PATH inicial sem Node/npm, testando instância única, fechamento, reabertura e preservação do histórico. Codex GPT-6 Luna e Kiro GPT-5.6 Luna responderam perguntas reais pelo pacote; fechar durante execução cancelou a tarefa e encerrou os processos da instância. As [evidências completas](https://github.com/ikaromm/Adelic/blob/v0.1.0/docs/validation.md) distinguem testes automatizados e execuções reais.

O destino precisa de Linux x86_64 e bibliotecas gráficas compatíveis com Electron. O host testado foi Arch/Omarchy com Wayland; outras distribuições ainda não foram validadas. CLIs e seus logins são externos ao pacote; uma CLI instalada via npm pode exigir seu próprio Node. Dados ficam em `~/.local/share/adelic` ou `ADELIC_DATA_DIR`. Feche o modo web antes de abrir o desktop usando a mesma base.

Claude Code tem adaptador implementado, mas a inferência com Claude Pro/Max ainda não foi validada neste ambiente. OpenCode oferece somente descoberta, sem execução. Bubblewrap, Graphify e ai-memory continuam externos. Acesso remoto/Tailscale, catálogo geral de MCPs e atualização automática ficam para versões futuras.

O desenvolvimento continua em `develop`, e a versão estável fica em `master`. O build local segue documentado em [desktop Linux](https://github.com/ikaromm/Adelic/blob/v0.1.0/docs/desktop-linux.md).
