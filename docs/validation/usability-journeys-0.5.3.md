# Usability journeys — 0.5.3

Date: 2026-10-08. Local working tree; no new release or publication from this work.

## Changes and journeys

| Journey | Previous friction | Implemented behavior |
| --- | --- | --- |
| Find a setting | Long page without search or categories | Search ignores accents, matches indexed titles/descriptions and keywords; categories, result count and empty state help navigation. |
| Edit settings while searching | Filtering could discard unsaved component state | Cards stay mounted while hidden; an unsaved project check survives changing the search. |
| Choose model, thinking and access | Overlapping approval and permissions menus, crowded controls | Primary composer row groups model, thinking and one Access menu; attachments/send have their own action group and project/run context appears below. |
| Understand access | Global workspace access and conversation approval were combined | Workspace sandbox changes only the global sandbox; approval changes only the conversation override, with an explicit inherit option and effective source. Internet approval remains forced/manual. SSH copy describes the remote user's permissions. |
| Create an SSH project | Leaving the form to configure a server loses context | A settings shortcut pauses the draft and searches SSH; Continue restores the form and focus, refreshes hosts and clears an invalid removed host. |
| Use terminal in several projects | Command draft can be mistaken for another project's terminal | Scope shows project/path/Local or SSH; changing conversation or project closes the panel. Remote read-only execution remains disabled and follows live access changes without reopening the panel. Long scope names stay bounded; preview warnings distinguish remote projects from remote browser clients. |
| Organize virtual subprojects | Folder deletion unavailable | Leaf folder deletion asks for confirmation, moves conversations to the parent/root, and preserves history and physical files. Children and active runs prevent deletion. |

The execution summary continues to show actual capabilities. Standalone conversations correctly show configured delegation; no project graph is implied for them. Default project orchestration and Graphify remain enabled.

## Validation

Audits and implementation used three GPT-6 Luna agents with separate settings, composer and journey scopes. The main agent reviewed integration; an independent Astra review found stale SSH host selection, focus restoration, misleading SSH sandbox copy and the standalone delegation summary. All four findings were fixed. A separate Sol review found stale terminal sandbox state, a lost remote-client preview warning and overflow from long project names; these were corrected with focused UI coverage.

Automated checks exercise the production web build with isolated temporary backend data and scripted providers. The new UX journeys do not spend model tokens or contact a real SSH server. Existing remote-host integration tests remain separate from the new draft journey test, which mocks host discovery.

The T3 collaborative preview was opened and retried with environment-port, localhost and 127.0.0.1 URLs. It returned `net::ERR_CONNECTION_REFUSED`, while the isolated loopback server returned HTTP 200 locally. Interactive visual validation in that preview could not be completed. Responsive layout, keyboard interaction, translations and user journeys are covered by repository E2E tests. Desktop (1280×800) and mobile (390×844) composer screenshots were generated by those tests and inspected: controls remain visible and do not overlap. Screenshot capture waits for the composer and disables transition animations.

Final checks passed:

- `npm run typecheck`.
- `npm run lint`: zero errors; nine existing warnings outside this UX change.
- `npm run format:check`.
- `npm test -- --maxWorkers=2`: 1,364 passed, one skipped, 89 files passed.
- `npm run build` (also included by the E2E script).
- `npm run test:e2e`: all 147 tests passed, including live terminal access, removed SSH host and remote-browser preview cases.
- `git diff --check`.

The isolated preview server was stopped after inspection attempts. Test data and screenshots stay outside tracked source; no credentials, global listeners or remote authentication settings were changed. The version remains 0.5.3.
