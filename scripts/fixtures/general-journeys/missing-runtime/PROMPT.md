Investigate why the project check fails. Read the project files and run a safe local probe for any missing executable and the check itself. Write `diagnosis.json` with fields `cause` (one of `missing-runtime`, `failing-check`, `invalid-config`, or `unknown`), `executable` (string naming the relevant command, or an empty string), `probeFoundOnPath` (boolean), `checkPassed` (boolean), and `recovery` (object with boolean fields `requiresInstallation` and `checkPassed`, plus string field `nextStep`). Derive booleans from observed results. `recovery.requiresInstallation` describes whether the recommended resolution would eventually require an installation; it is a recommendation, not an instruction to install now. `nextStep` must state a safe, concise action such as checking PATH/configuration or requesting an approved runtime. Do not install software or modify source or the check script.
